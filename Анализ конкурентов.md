# Анализ конкурентов MirrorVote

> Дата исследования: 2026-05-19

MirrorVote — AI-помощник в примерочной: загрузить 1–6 фото нарядов → AI обработка (Simple Look) → AI-рейтинг с выбором события → голосование друзей по публичной ссылке → экспорт коллажа.

## Прямые конкуренты — подробно

### 1. Lookly — AI Style Advisor
- **Ссылка:** https://apps.apple.com/us/app/lookly-ai-style-advisor/id6746429531
- **Платформа:** iOS
- **Функции:** Загрузить фото → выбрать событие → AI стиль-скор + рекомендации
- **Монетизация:** Не раскрыта
- **Сходство с MirrorVote:** Очень высокое — выбор события + AI рейтинг
- **Отличие:** Нет голосования друзей, нет обработки фото, нет сравнения нескольких образов, нет экспорта

### 2. Outafit
- **Ссылка:** https://outafit.com/
- **Платформа:** Web
- **Функции:** Загрузить фото → AI рейтинг 1–10 (координация цветов, посадка, стиль, уместность события, тренды)
- **Монетизация:** Не раскрыта
- **Сходство с MirrorVote:** Высокое по рейтингу
- **Отличие:** Нет голосования, нет обработки фото, нет сравнения нескольких нарядов

### 3. OutfitScore
- **Ссылка:** https://outfitscore.com/
- **Платформа:** Web
- **Функции:** Анализ гармонии цветов, посадки, стиля, уместности события; оценка 0–100
- **Монетизация:** Бесплатно (5 анализов/день на free)
- **Отличие:** Более детальное разложение оценки, но нет голосования и обработки фото

### 4. StylePal
- **Ссылка:** https://www.stylepal.app/
- **Платформа:** Web
- **Функции:** Сравнение двух нарядов 1-на-1, AI объясняет, какой лучше и почему
- **Сходство с MirrorVote:** Сравнение нарядов (аналог Pick Best)
- **Отличие:** Только 2 наряда, нет голосования друзей, нет обработки фото

### 5. Snap — AI Outfit Rating
- **Ссылка:** https://apps.apple.com/us/app/snap-ai-outfit-rating/id6754261974
- **Платформа:** iOS
- **Функции:** Анализ посадки, материала, гармонии цветов, силуэта; режим сравнения 1-на-1
- **Отличие:** Есть режим сравнения, нет голосования и обработки фото

### 6. FashionAdvice.ai
- **Ссылка:** https://www.fashionadvice.ai/
- **Платформа:** Web
- **Функции:** AI рейтинг 1–10 + персонализированные советы стилиста
- **Отличие:** Акцент на персональные советы, нет сравнения и голосования

### 7. Combyne
- **Ссылки:** https://apps.apple.com/us/app/combyne-your-perfect-outfit/id989727742 / Google Play
- **Платформа:** iOS + Android
- **Функции:** Создание коллажей нарядов, шеринг с друзьями, голосование в челленджах, обратная связь от комьюнити
- **Монетизация:** Freemium
- **Сходство с MirrorVote:** Есть голосование и экспорт коллажей
- **Отличие:** Нет AI-рейтинга, нет обработки фото, голосование публичное (комьюнити), не только друзья

### 8. Vote Social
- **Ссылка:** https://apps.apple.com/us/app/vote-social-polling-evolved/id1579682514
- **Платформа:** iOS
- **Функции:** Голосование между двумя фото, комьюнити голосует и комментирует
- **Сходство с MirrorVote:** Голосование по фото нарядов
- **Отличие:** Только 2 варианта, публичное (не личное), нет AI-рейтинга и обработки

## Виртуальные примерочные (смежный сегмент, B2B)

Это платформы для интернет-магазинов — позволяют примерить конкретную одежду из каталога. Не конкурируют напрямую, но занимают слово «примерочная» в поиске.

### FitRoom
- **Ссылка:** https://fitroom.app/
- **Функции:** API для магазинов — загрузить фото → примерить одежду из каталога
- **Монетизация:** B2B API

### FASHN AI Virtual Try-On
- **Ссылка:** https://fashn.ai/virtual-fitting-rooms
- **Функции:** API — миксовать наряды, визуализировать разные размеры/фигуры
- **Монетизация:** B2B API

### My Fitting Room
- **Ссылка:** https://myfittingroom.ai/
- **Функции:** AI-примерка одежды из каталогов магазинов
- **Монетизация:** B2B

### WeShop AI
- **Ссылка:** https://www.weshop.ai/tools/virtualtryon
- **Функции:** Виртуальная примерка и замена одежды в фото
- **Монетизация:** Freemium

## AI-стилисты и гардеробные приложения

### Dressly — AI Outfit Stylist
- **Ссылки:** https://apps.apple.com/us/app/dressly-ai-outfit-stylist/id6738174180 / Google Play
- **Функции:** Анализ цветов, предложение образов, синхронизация с календарём и погодой, рейтинг нарядов
- **Монетизация:** Freemium
- **Отличие от MirrorVote:** Комплексный ассистент (гардероб + рейтинг + погода), нет голосования и обработки фото

### Acloset — AI Fashion Assistant
- **Ссылка:** https://apps.apple.com/us/app/acloset-ai-fashion-assistant/id1542311809
- **Функции:** Оцифровка гардероба, ежедневные рекомендации по погоде и графику, анализ цветов и силуэтов
- **Монетизация:** Freemium

### Style DNA
- **Ссылка:** https://styledna.ai/
- **Функции:** Анализ лица → персональная цветовая палитра → советы по стилю

### Alta
- **Ссылка:** https://www.altadaily.com/
- **Функции:** AI-стилист для конкретных событий (свидание, собеседование, поездка)
- **Монетизация:** Подписка

### Whering
- **Ссылка:** https://whering.co.uk/
- **Функции:** Цифровой гардероб, комьюнити мудборды, обмен идеями со стилистами

## Российский рынок

### Virton

## Уникальное позиционирование MirrorVote

**MirrorVote — единственное приложение, которое в одном месте совмещает:**

1. AI обработку фото (студийный фон, свет, поза, без телефона)
2. AI-рейтинг с выбором события (офис, свидание, вечеринка и т.д.)
3. Голосование друзей по публичной ссылке без регистрации
4. Экспорт коллажа в JPG

Сценарий «я в примерочной — хочу спросить подруг» не закрыт ни одним конкурентом полностью.

## Стратегические выводы

### Угрозы
- Lookly и аналоги выходят на рынок быстро с похожим AI-рейтингом
- ВКонтакте может добавить рейтинг/голосование поверх примерочной и закрыть российский рынок за счёт аудитории
- Пользователи могут комбинировать отдельные инструменты (Lookly + Vote Social + Fits)

### Возможности
- **TG Mini App** (уже в TODO) — быстрый выход на аудиторию Telegram без App Store
- **Гардероб** (как Dressly, Acloset) — удержание пользователей между визитами в магазин
- **Шеринг в соцсети** — вирусный рост через TikTok/Instagram (как Vote Social)
- **Интеграция с магазинами** — показывать похожие товары после оценки (монетизация через партнёрство)
- **На российском рынке конкурентов нет** — окно для роста
